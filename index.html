What ntn-observability does

ntn-observability is an ns-3 module that records satellite positions, measured radio KPIs and control events from a non-terrestrial network simulation and exports them as InfluxDB line protocol, NetSimulyzer scene JSON and CZML. A reproducibility manifest and a single metric schema keep every exported measurement traceable to the run and the code that produced it.

What it models

The module is a telemetry and visualization layer, not a radio model. It takes what the simulation already measures (PHY SINR, TBLER, sink goodput, SGP4 positions, elevation and slant range, and control events such as handover, timing advance, SIB19 and DRX) and writes it out in the formats operators use. NtnInfluxSink emits InfluxDB v2 line protocol with key escaping, file or UDP transport, run-id tags and a bounded buffer that drops and counts the oldest points. NtnSceneRecorder is a single tap that reads mobility positions in ECEF or local ENU (converted to ECEF), KPIs and events, and fans them out to the NIST NetSimulyzer 1.0 JSON schema and to CZML for a Cesium globe. Serving and handover links travel alongside positions, so a viewer shows which satellite serves which terminal at a time that maps back to simulation time.

A header-only schema names every measurement, tag and field once, using 3GPP TS 28.552 and TS 32.425 measurement names and O-RAN E2SM-KPM identities. NtnReproManifest records git SHA, ns-3 version, scenario, seed, TLE epoch and command-line arguments, and can be written and read back. Per-flow KPM series come from NtnOranAiFlowMonitor in ntn-traffic. A Docker stack with InfluxDB 2.7, Grafana 10.4 and Telegraf ships four dashboards (Overview, Handover, Radio, ISL), and a script traces each Grafana panel back to the code that emits it. The band tag follows the carrier as an IEEE Std 521 letter band.

Install

Every module ships in the ready-built container image of the toolkit (version 3.0.1):

docker pull uzairdocker69/ns3-ntn-toolkit:latest
docker run --rm -it uzairdocker69/ns3-ntn-toolkit:latest bash

To build from source, clone ns3-ntn-toolkit, which vendors this module under contrib/, or follow the README of this repository (branch ntn-observability-v4).
